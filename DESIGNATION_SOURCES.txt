# Working-document roots for the designation register's master sweep.
#
# One absolute path per line. Blank lines and # comments ignored.
# Absent or empty: the sweep reads the published mirror only, as it did
# before the master sweep existed.
#
# WHY THIS FILE IS NOT THE PUBLIC REGISTER'S SOURCE
# Designations found only in working documents are NOT written to
# designations/index.html or DESIGNATIONS.csv, both of which are public.
# An unpublished instrument's designation can reveal work that is not
# ready to be public — its existence, its scope, sometimes its subject.
# The master sweep therefore produces a separate, gitignored local
# register for the author's own lookup. See scripts/build_designations.py,
# "TWO REGISTERS".
#
# THREE SPELLINGS PER ROOT, DELIBERATELY
# The same folder is reached by different paths depending on where this script
# runs: directly on the machine (~/OneDrive/Desktop/Projects/...), or inside the
# desktop workspace, where connected folders are mounted under $HOME/mnt/ --
# as $HOME/mnt/Projects/... when the Projects folder is connected, or as
# $HOME/mnt/Desktop/Projects/... when the whole Desktop is. All three are
# listed; whichever resolves is used, and paths that do not resolve are skipped
# without complaint. Only a run where NO root resolves is reported.
# Connect either Projects or Desktop for a workspace run, not both: the script
# does not de-duplicate, so two resolving spellings of one folder count its
# masters twice.
#

# Desktop\Projects and several were renamed, so no root resolved and the
# working sweep had silently become a published-only sweep. Paths re-taken
